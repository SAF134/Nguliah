# Panduan Folder Aset Gambar Nguliah

Folder ini (`assets/images/`) digunakan untuk menyimpan aset gambar statis aplikasi Nguliah:

1. **`qris.png`**
   - Gambar kode QRIS untuk dukungan sukarela pengembangan aplikasi.
   - Format: PNG atau JPG.
   - Rekomendasi resolusi: 512 x 512 px atau 1024 x 1024 px.

2. **`developer.png`**
   - Foto profil pengembang aplikasi yang akan ditampilkan di lembar *Tentang Pengembang & Dukungan*.
   - Format: PNG atau JPG.
   - Rekomendasi resolusi: 400 x 400 px (aspek rasio 1:1 / lingkaran).

Apabila berkas belum diletakkan di folder ini, aplikasi akan secara otomatis menampilkan kartu informasi dan placeholder ikon yang rapi.
